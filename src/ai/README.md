# AI Module

Prompt templates, model configurations, inference pipelines, and evaluation suites. AI-specific assets that are version-controlled like code.

## Sections

- **prompts/** — Versioned prompt templates (summarize-note.v1.txt, suggest-codes.v1.txt)
- **models/** — Model routing and configuration
- **pipelines/** — Inference pipelines (summarization-pipeline.ts, coding-pipeline.ts)
- **evaluation/** — Prompt evaluation suites and test fixtures
