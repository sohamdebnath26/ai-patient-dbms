# Presentation Layer

React components, pages, hooks, layouts, and the design system. Depends on the application layer.

## Sections

- **components/** — Feature components: PatientCard, PatientSearchBar, ClinicalNoteEditor, AISummarizeButton
- **pages/** — Route-level page components organized by feature area
- **hooks/** — Custom hooks: usePatientSearch, useAISummarize, useClinicalSummary
- **layouts/** — AppShell, TenantLayout, AuthLayout
- **design-system/** — Shared UI primitives: Button, Input, Modal, Card, Table
